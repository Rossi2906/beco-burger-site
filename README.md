# Beco Burger

Landing page responsiva de uma lanchonete fictícia, feita com HTML, CSS e JavaScript puro. O cardápio permite adicionar itens à sacola e acompanhar o total.

## Site publicado

[Acessar o Beco Burger](https://rossi2906.github.io/beco-burger-site/)

## Executar

Abra `index.html` no navegador. Não é necessário instalar dependências nem executar um servidor.

## Publicar no GitHub Pages

O GitHub Pages já está configurado neste repositório para publicar a branch `main`, na pasta `/ (root)`. Para configurar em outro repositório:

1. Envie os arquivos deste projeto a um repositório público.
2. No repositório, abra **Settings → Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**, escolha `main` e a pasta `/ (root)`, depois salve.

As fotos e as fontes são carregadas de serviços externos e precisam de conexão com a internet.
